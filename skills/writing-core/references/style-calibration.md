# Style calibration

Use this when examples are available.

## Evidence order

1. User-approved final writing.
2. User edits that replaced an AI draft.
3. User-authored raw writing in the same genre.
4. Human-authored exemplars with known provenance.
5. Generic style guidance.

A newer rule does not beat an accepted example automatically. Investigate the mismatch.

## Extract DNA, not phrases

Measure or describe:

- how quickly the point appears;
- sentence-length distribution, not one target length;
- common sentence shapes;
- concrete vs abstract noun ratio;
- certainty and hedging;
- punctuation habits;
- transitions;
- use of examples, humour and first person;
- how much context is left for the speaker or reader to infer;
- how the style changes by audience.

Do not copy distinctive phrases or mimic errors.

## Pre-2022 external exemplars

When looking for outside examples to study, pre-2022 material can reduce the chance that the sample itself was AI-generated. Treat that as a provenance heuristic, not a quality rule. Older writing can still be bad, and some techniques later became associated with AI because models learned them from human writing.

The user's own approved work outranks publication date.

## Stable vs genre-specific

Store only stable preferences in a general voice profile. Keep genre-specific behaviour in the genre skill.

Example:

- Stable: direct point first; concrete nouns; low tolerance for hedging.
- Presentation: sparse slide copy; presenter supplies the connective story.
- Email: slightly warmer; explicit next action.
- Social: conversational; imperfections can remain.
