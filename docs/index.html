The workshop does not move on because the answer sounds good.

Each phase has a gate. Research and drafting happen first. The critics review independently. Critical issues go back through the rig.

  3. 03

    Converge

    Shared concerns become must-fix items. You revise, accept a trade-off or stop.

Before you install it

Is this just a long prompt?

No. The workshops are phase-gated, write persistent files and run independent review agents at each checkpoint. A normal chat can imitate the tone, but it skips the structure and convergence rules.

Does it replace real customer research?

No. It catches obvious gaps before customers see them. Dynamic personas are a pressure test, not proof of demand. Real buyers still decide whether the offer works.

Do I need to know the Hormozi books?

No. The workshops apply the relevant questions and formulas one phase at a time. The repository is an independent open-source implementation inspired by $100M Offers and $100M Leads.

Can I use only one workshop?

Yes. Each workshop runs on its own. The lead workshop can audit an existing offer, and the copy gate can review any customer-facing text.

Customers will test the idea either way.
